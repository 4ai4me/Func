# 이하연 수학 교실 — 공통수학2 함수와 그래프 탐구 프로젝트 (`대응일까, 함수일까?`)

고등학교 수학 교육과정(공통수학2 — 함수 단원) 수업을 위한 **학생·교사 승인제 통합 탐구 및 평가 플랫폼**입니다.
[`https://4ai4me.github.io/Props/`](https://4ai4me.github.io/Props/)와 동일한 시스템 아키텍처, 인증/보안 구조, 실시간 동기화 및 교사용 수사 기록실 프레임워크를 기반으로 구축되었습니다.

## 1. 주요 기능 및 기본 틀 구성

- **학생·교사 승인제 게이트웨이 (`AuthGateView` — `Props` 수업과 통합 계정 연동)**:
  - **기존 `Props` 수업 학습자 무가입 즉시 연동**: [`https://4ai4me.github.io/Props/`](https://4ai4me.github.io/Props/)와 동일한 Firebase 프로젝트(`tonal-nimbus-x3kqt`) 및 Firestore 데이터베이스(`ai-studio-526dd59d-4569-47c9-82fd-c81701392bbd`)의 `student_registrations` 컬렉션을 공유합니다. 이미 `Props`(명제 수업)에서 가입·승인된 학생은 다시 가입할 필요 없이 기존 학적 정보로 즉시 로그인되며, 동일 브라우저에서는 자동 입장됩니다.
  - **과목별 답안 무손실 분리 저장 (`funcWorksheet`)**: 동일한 학생 문서를 공유하면서도 기존의 `Props`(명제) 탐구 답안·교사 평가는 최상위 필드에 그대로 보존하고, `Func`(함수) 탐구 답안·교사 평가는 `worksheetJson` 내부의 `funcWorksheet` 네임스페이스에 분리 저장하여 두 수업 간 데이터 덮어쓰기를 원천 차단합니다.
  - **학교 공용 네트워크 최적화 (MAC 주소 해시 기반 식별)**: 동일 공인 IP를 사용하는 학교 와이파이·컴퓨터실 환경을 고려하여 IP 검사를 배제하고, 기기 고유 MAC 주소 식별자(`deviceHash`) 및 학번 기준으로 중복 신청을 방지합니다.
  - **교사(관리자) 모드**: 지정된 관리자 Google 계정(`liha1634@gmail.com` / `planitia4ai@gmail.com`) OAuth 인증을 통해서만 교사용 수사 기록실 및 학생 승인 패널에 접근할 수 있습니다.
- **실시간 클라우드 자동 저장 및 강제 저장**:
  - 학생이 작성하는 탐구 답안은 `localStorage`와 Firebase Firestore(`student_registrations/{studentKey}`)에 실시간 Debounce 자동 저장되며, 상단 헤더의 **`[지금 저장]`** 버튼으로 즉시 강제 동기화할 수 있습니다.
- **스마트 수식 입력 도우미 (`MathSymbolInputBar` & `MathText`)**:
  - 함수 기호(`f(x)`, `g(x)`, `(g∘f)(x)`, `f⁻¹(x)`, `∘`, `↦`, `→`), 부등호·등호(`≥`, `≤`, `≠`, `±`), 제곱·근호(`²`, `³`, `√(□)`), 논리·집합 기호(`∴`, `∵`, `⇒`, `⇔`, `∈`, `∉`, `⊂`, `∪`, `∩`)를 원클릭 버튼 및 키보드 단축어로 입력할 수 있습니다.
  - 벡터 SVG 근호 갈고리와 윗줄(Vinculum)이 결합된 `<MathText />` 렌더러를 통해 루트 수식을 명확하게 표시합니다.
- **학생용 「평가 결과」 모달 (`StudentEvaluationModal`)**:
  - 차시별 완료 현황, 자동 루브릭 분석, 교수자 역량 평정 점수(0~3점) 및 맞춤 피드백을 실시간으로 확인하고 인쇄할 수 있습니다.
- **교사용 수사 기록실 (`TeacherView`)**:
  - 학생 가입 신청 실시간 승인/반려, 기기 잠금 초기화, 실시간 접속 로그(오전/오후 필터), 학생 이름 검색 및 다중 열 필터링, 비모달(Modeless) 상세 비교 창, 루브릭 채점·피드백 저장, 개별 평가서 PDF 인쇄 및 CSV 내보내기/가져오기를 지원합니다.

## 2. 1차시: 함수의 뜻과 그래프 (`Lesson1View`)

교과서 지문 및 시각 자료를 바탕으로 6단계 인터랙티브 탐구 활동지를 제공합니다. 모든 서술형·단답형 입력칸은 학습자가 스스로 생각하여 작성할 수 있도록 내부 예시 문구(`placeholder`)를 비워두었으며, 필요한 경우에만 외부의 **`💡 힌트 보기`** 토글 버튼을 눌러 단계별 가이드를 확인할 수 있습니다.

1. **1단계 — 대응과 함수 (`[생각 열기]` · `[보기]` · `[문제 1]`)**:
   - **인터랙티브 화살표 대응 다이어그램**: 집합 $X$(대한민국, 독일, 프랑스, 미국)의 원소와 집합 $Y$(원, 유로, 달러, 파운드)의 원소를 클릭하여 직접 화살표로 연결하고 함수 여부를 판정합니다 (`💡 생각 열기 힌트 보기` 지원).
   - **`[문제 1]` 함수 판별 활동지**: 세 대응 관계 (1), (2), (3) 중 함수를 찾고, 정의역·공역·치역을 구하며 함수가 아닌 이유(원소 누락 또는 중복 대응)를 스스로 서술합니다.
2. **2단계 — 정의역과 치역 (`[보기]` · `[문제 2]`)**:
   - 정의역이 명시되지 않은 함수에서 함숫값이 정의되는 실수 전체의 집합을 탐구하며, 일차함수 $y=2x+1$과 이차함수 $y=-x^2+3$의 **그래프 힌트**를 토글로 확인하고 정의역·치역을 직접 구해 검증합니다.
3. **3단계 — 서로 같은 함수 (`[탐구+ 문제 3]`)**:
   - 정의역 $\{-1, 0, 1\}$에서 두 함수 $f(x)=|2x|$와 $g(x)=2x^2$의 함숫값 표를 완성하고, 함수의 식이 달라도 정의역의 모든 원소에서 함숫값이 같으면 서로 같은 함수($f=g$)가 됨을 확인합니다.
4. **4단계 — 함수의 그래프 (`[문제 4]` · `[문제 5]`)**:
   - **인터랙티브 좌표평면 점 찍기 & 직선 긋기 (`[문제 4]`)**: 함수 $y=-2x+3$에 대하여 (1) 정의역이 $\{0, 1, 2, 3\}$일 때 좌표평면 격자점을 직접 클릭해 4개의 점을 찍고, (2) 정의역이 실수 전체일 때 두 점을 클릭해 직선 그래프를 직접 그립니다.
   - **수직선 판별법 개별 시뮬레이션 (`[문제 5]`)**: (1) 포물선, (2) 원, (3) 수평 반직선 형태의 각 그래프마다 독립된 슬라이더로 수직선 $x=a$를 움직이며 교점 개수를 실시간으로 확인하고 함수의 그래프 여부를 판별합니다.
5. **5단계 — 실생활 함수 모델링 (`탐구 05`)**:
   - 실생활 대응 사례의 함수 여부를 판별하고, 주제별 `💡 힌트 보기` 가이드를 참고하여 나만의 실생활 함수 $f: X \to Y$의 제목, 정의역 $X$, 공역 $Y$, 대응 규칙, 함수가 되는 이유 및 반례를 스스로 설계합니다.
6. **6단계 — 도전!! 실생활 함수 (`탐구 06` — 도전 1 & 도전 2)**:
   - **도전 1 (`AI 얼굴 인식은 함수일까?`)**: AI 얼굴 인식 기계 A, B, C의 사진(정의역) → 이름(공역) 대응을 분석하여 함수 여부를 판별하고, 오류가 있는 기계 B(중복 출력)와 기계 C(인식 실패 누락)를 엔지니어로서 직접 수리합니다.
   - **도전 2 (`고장 난 자판기를 고쳐라!`)**: 자판기 버튼(정의역 $X$) → 음료(공역 $Y$) 대응에서 고장 난 자판기 가, 나, 다의 원인을 진단·수리하고, 나만의 정상 작동 음료 자판기 대응표를 설계합니다.
   - **탐구 기록 JSON 내보내기**: 작성한 도전 1·도전 2 답안을 JSON 파일로 즉시 백업·제출할 수 있습니다.
