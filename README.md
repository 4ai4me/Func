# 이하연 수학 교실 — 공통수학2 함수와 그래프 탐구 프로젝트 (`대응일까, 함수일까?`)

고등학교 수학 교육과정(공통수학2 — 함수 단원) 수업을 위한 **학생·교사 승인제 통합 탐구 및 평가 플랫폼**입니다.
[`https://4ai4me.github.io/Props/`](https://4ai4me.github.io/Props/)와 동일한 시스템 아키텍처, 인증/보안 구조, 실시간 동기화 및 교사용 수사 기록실 프레임워크를 기반으로 구축되었습니다.

---

## 1. 주요 기능 및 기본 틀 구성

- **학생·교사 승인제 게이트웨이 (`AuthGateView`)**:
  - **학생 모드**: 학교, 학년(1~6학년), 반, 번호, 생년월일(6자리 또는 8자리), 이름을 입력하여 신규 가입 신청 및 승인 후 입장.
  - **학교 공용 네트워크 최적화 (MAC 주소 해시 기반 식별)**: 동일 공인 IP를 사용하는 학교 와이파이·컴퓨터실 환경을 고려하여 IP 검사를 배제하고, 기기 고유 MAC 주소 식별자(`deviceHash`) 및 학번 기준으로 중복 신청을 방지합니다.
  - **교사(관리자) 모드**: 지정된 관리자 Google 계정(`liha1634@gmail.com` / `planitia4ai@gmail.com`) OAuth 인증을 통해서만 교사용 수사 기록실 및 학생 승인 패널에 접근할 수 있습니다.
- **실시간 클라우드 자동 저장 및 강제 저장**:
  - 학생이 작성하는 탐구 답안은 `localStorage`와 Firebase Firestore(`student_registrations/{studentKey}`)에 실시간 Debounce 자동 저장되며, 상단 헤더의 **`[지금 저장]`** 버튼으로 즉시 강제 동기화할 수 있습니다.
- **스마트 수식 입력 도우미 (`MathSymbolInputBar` & `MathText`)**:
  - 함수 기호(`f(x)`, `g(x)`, `(g∘f)(x)`, `f⁻¹(x)`, `∘`, `↦`, `→`), 부등호·등호(`≥`, `≤`, `≠`, `±`), 제곱·근호(`²`, `³`, `√(□)`), 논리·집합 기호(`∴`, `∵`, `⇒`, `⇔`, `∈`, `∉`, `⊂`, `∪`, `∩`)를 원클릭 버튼 및 키보드 단축어로 입력할 수 있습니다.
  - 벡터 SVG 근호 갈고리와 윗줄(Vinculum)이 결합된 `<MathText />` 렌더러를 통해 루트 수식을 명확하게 표시합니다.
- **학생용 「평가 결과」 모달 (`StudentEvaluationModal`)**:
  - 차시별 완료 현황, 자동 루브릭 분석, 교수자 역량 평정 점수(0~3점) 및 맞춤 피드백을 실시간으로 확인하고 인쇄할 수 있습니다.
- **교사용 수사 기록실 (`TeacherView`)**:
  - 학생 가입 신청 실시간 승인/반려, 기기 잠금 초기화, 실시간 접속 로그(오전/오후 필터), 학생 이름 검색 및 다중 열 필터링, 비모달(Modeless) 상세 비교 창, 루브릭 채점·피드백 저장, 개별 평가서 PDF 인쇄 및 CSV 내보내기/가져오기를 지원합니다.

## 2. 시스템 아키텍처

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        클라이언트 브라우저 계층                         │
│  (PC, 태블릿, 모바일 반응형 UI / iOS Safari 줌 방지 / Tailwind CSS)     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
         ┌──────────────────────────┴──────────────────────────┐
         ▼                                                     ▼
┌─────────────────────────────────┐   ┌──────────────────────────────────┐
│      학생 모드 (Student Mode)    │   │      교사 모드 (Teacher Mode)     │
│  - 학교/학년/반/번호/생년월일 가입 │   │  - 관리자 구글 OAuth 인증        │
│  - 기기 고유 MAC 주소 해시 식별  │   │  - 학생 가입 승인 / 반려 / 관리  │
│  - 차시별 단계형 함수 탐구 작성  │   │  - 학생별 평가 진행율(%) 배지    │
│  - 힌트 토글 (열기/다시 숨기기)  │   │  - 실시간 접속 로그 & 필터링     │
│  - 실시간 자동 저장 (Debounce)   │   │  - 학생 이름 검색 & 열 필터링    │
│  - 평가 결과 모달 & PDF 인쇄    │   │  - 비모달(Modeless) 상세 비교창  │
└────────────────┬────────────────┘   └────────────────┬─────────────────┘
                 │                                     │
                 ▼                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        Firebase Firestore 백엔드                       │
│  - student_registrations/{studentKey}: 가입 상태, 학적정보, 답안 JSON  │
│  - device_locks/{deviceHash}: 기기 고유 MAC 주소 기반 중복 가입 방지    │
│  - student_access_logs/{logId}: 학생 실시간 접속 및 저장 감사 기록      │

```
